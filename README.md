# One Letter for Your Day

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)

Entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

The program writes exactly one letter — **O** — to `/output/entry.txt`.
Behind it sits the word for the day: *overdrive*. A day spent flat out,
building bounty after bounty, never letting up.

Run with Node 22+, standard library only, fully deterministic:

```sh
node main.ts
```
